# Deep-RAG 评估系统

完整的评估流程和工具，用于量化系统质量。

## 📋 评估数据集

**test_dataset.json** - 50个真实查询：
- 10个简单问题（基础概念、环境配置）
- 25个中等问题（代码实现、概念对比）
- 15个复杂问题（深度对比、复杂实现、问题解决）

**数据集构成**：
- 本地文档查询：35个（70%）
- GitHub API查询：5个（10%）
- Web搜索查询：5个（10%）
- 混合/复杂查询：5个（10%）

## 🚀 快速开始

### 1. 运行评估

```bash
# 进入项目目录
cd deep-rag

# 运行评估脚本
python evaluation/run_evaluation.py
```

### 2. 评估流程

对于每个查询，系统会：
1. 运行查询，记录响应时间
2. 展示答案和期望关键词
3. 自动计算关键词覆盖率
4. 要求人工打分（0-5分，或按Enter使用自动打分）
5. 对于低分答案，记录错误类型

**打分标准**：
- 5分：完全正确，信息完整
- 4分：大部分正确，有小瑕疵
- 3分：部分正确，信息不完整
- 2分：有少量正确信息，但主要错误
- 1分：几乎完全错误
- 0分：完全错误或无法回答

**自动打分规则**（按Enter使用）：
- 关键词覆盖率 ≥80% → 5分
- 关键词覆盖率 ≥60% → 4分
- 关键词覆盖率 ≥40% → 3分
- 关键词覆盖率 ≥20% → 2分
- 关键词覆盖率 >0% → 1分
- 关键词覆盖率 =0% → 0分

### 3. 查看结果

评估完成后会生成两个文件：
- `evaluation/results.json` - 详细的评估数据
- `evaluation/report.md` - 格式化的评估报告

## 📊 评估报告内容

生成的评估报告包含：

### 核心指标
- 平均准确率（百分比和得分）
- 平均响应时间
- 完全正确率、部分正确率、错误率

### 按难度分析
- 简单/中等/复杂查询的准确率和响应时间对比

### 按类别分析
- 每个查询类别的准确率排名

### 错误分析
- 错误类型统计（幻觉、信息遗漏、理解错误等）
- 典型错误案例展示（前5个）

### 改进建议
- 基于评估结果自动生成的改进方向

## 🔧 配置说明

### 修改评估脚本

在 `run_evaluation.py` 的 `run_query()` 函数中，替换为你的实际Agent调用：

```python
def run_query(query: str) -> tuple[str, float]:
    # 替换这部分为实际代码
    from src.agent_executor_v2 import agent
    start = time.time()
    answer = agent.run(query)
    elapsed = time.time() - start
    return answer, elapsed
```

### 自定义数据集

编辑 `test_dataset.json`，每个查询包含：
- `id`: 唯一标识
- `query`: 查询文本
- `category`: 类别（用于统计分析）
- `difficulty`: 难度（easy/medium/hard）
- `expected_contains`: 期望的关键词列表
- `source_type`: 数据源类型（用于分析工具路由准确性）

## 💡 使用建议

### 初次评估
1. 先运行10-20个查询，了解系统表现
2. 识别主要问题类型
3. 针对性优化后再全量评估

### 对比评估
1. 保存优化前的 `results.json` 和 `report.md`
2. 进行系统优化
3. 重新运行评估
4. 对比两次报告，验证优化效果

### 持续改进
1. 每次重大更新后运行评估
2. 维护评估历史记录
3. 跟踪关键指标的变化趋势

## 📈 评估频率建议

- **开发阶段**：每次重大功能更新后评估
- **优化阶段**：每次优化后对比评估
- **稳定阶段**：每周/每月定期评估

## 🎯 目标设定

### 基础目标（应届生项目）
- 平均准确率：70%+
- 简单问题准确率：85%+
- 平均响应时间：<3秒

### 优秀目标（进阶项目）
- 平均准确率：80%+
- 简单问题准确率：95%+
- 中等问题准确率：75%+
- 平均响应时间：<2秒

### 卓越目标（生产级）
- 平均准确率：90%+
- 所有难度准确率：85%+
- 平均响应时间：<1.5秒
- 幻觉问题：<3%

## 🔍 故障排查

### 问题：脚本无法运行Agent
**解决**：检查 `run_query()` 函数中的import路径是否正确

### 问题：评估速度太慢
**解决**：可以先评估前10-20个查询，或使用更快的模型

### 问题：结果不理想
**解决**：
1. 检查数据集是否合理
2. 查看典型错误案例，找出问题根源
3. 针对性优化后重新评估

## 📞 需要帮助？
