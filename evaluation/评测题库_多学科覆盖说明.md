# 多学科评测题库说明（v4 · 细化分支 + 免费联网回退）

- 时间：2026-07-18
- 题库：`evaluation/multidim_cases.json`
- 题量：**197**（学科 **29**，细化分支各 1 题为主）

## 原则

1. **每个细化分支 1 题**（不是整门学科只 2–4 题）。
2. 本地库优先：`proj_work` / `proj_thesis` / `proj_psychology` / `proj_social`。
3. **本地无依据 → 免费 DuckDuckGo + 项目 get_llm** 补答（`allow_refuse` 题也会尝试联网补齐）。
4. **拒识题** `expect_refuse=true` 且 `web_fallback=false`：**永不联网**，专测不瞎编。

## 联网回退（默认开）

```text
graph.query(本地库)
  → no_knowledge / 拒答 / 空答
  → free_web_answer: DuckDuckGo 检索 + get_llm/get_llm_with_fallback 总结
  → 答案前缀【来源：免费联网...】
```

- 开关：`--web-fallback` / `--no-web-fallback`
- 超时：`--web-timeout 120`
- 不走高成本 CPA grok-4.5 作为评测默认（可用免费链路）。
