## 🔍 模块2：MultiPathRetriever（多路推理）

### 工作原理

```python
def retrieve_multipath(query, top_k, paths):
    """
    3步并行检索 + RRF融合：
    
    Step 1：并行执行3条路径
      Path 1: simple（向量检索）
        - 直接query → 向量数据库
        - 速度最快（~10ms）
      
      Path 2: smart（查询优化+向量）
        - query → 改写 → 向量数据库
        - 准确率更高（~15ms）
      
      Path 3: expanded（查询扩展+融合）
        - query → 多查询 → 向量数据库 → 融合
        - 召回率最高（~25ms）
    
    Step 2：计算每条路径得分
      score = 平均相似度 × 置信度权重
      - high: 1.2
      - medium: 1.0
      - low: 0.8
    
    Step 3：RRF融合
      公式：RRF_score(doc) = Σ 1/(k + rank_i)
      k = 60（常数）
      rank_i = 文档在第i条路径中的排名
    
    Step 4：选择最佳路径
      best_path = max(paths, key=lambda p: p.score)
    """
```

### RRF融合详解

```python
# 示例：3条路径检索同一查询
# 
# Path1（simple）排名：
#   [doc1(rank=1), doc2(rank=2), doc3(rank=3)]
#
# Path2（smart）排名：
#   [doc2(rank=1), doc1(rank=3), doc4(rank=2)]
#
# Path3（expanded）排名：
#   [doc1(rank=2), doc2(rank=3), doc5(rank=1)]

# RRF计算（k=60）：
doc1_rrf = 1/(60+1) + 1/(60+3) + 1/(60+2) = 0.0164 + 0.0159 + 0.0161 = 0.0484
doc2_rrf = 1/(60+2) + 1/(60+1) + 1/(60+3) = 0.0161 + 0.0164 + 0.0159 = 0.0484
doc3_rrf = 1/(60+3) = 0.0159
doc4_rrf = 1/(60+2) = 0.0161
doc5_rrf = 1/(60+1) = 0.0164

# 最终排序：doc1 ≈ doc2 > doc5 > doc4 > doc3
# 
# 原理：
# - 出现在多条路径 → 得分高（doc1, doc2）
# - 排名靠前 → 得分高
# - 自动平衡不同路径的权重
```

### 问题2：RRF融合可能降低精度

```python
# 场景：Path1找到完美答案（相似度0.95）
#       Path2/3找到低质量结果（相似度0.6）
# 
# RRF融合后：完美答案可能被稀释

# 示例：
Path1: [doc1(sim=0.95), doc2(0.85), doc3(0.75)]
Path2: [doc4(0.65), doc5(0.60), doc1(0.55)]  # doc1被降级
Path3: [doc6(0.68), doc1(0.58), doc7(0.52)]

# RRF后：doc1排名下降（因为在Path2/3排名低）

# 解决方案：
# 1. 加权RRF：给高质量路径更高权重
# 2. 阈值过滤：相似度<0.5的结果不参与融合
```
