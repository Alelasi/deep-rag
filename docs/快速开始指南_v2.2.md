## 🚀 场景1：增量索引（推荐）

**适用场景**：文档经常变动，需要快速同步

### Step 1：首次索引

```python
from src.retrieval.incremental_indexer import IncrementalIndexer

# 创建索引器
indexer = IncrementalIndexer(
    collection_name="my_docs",
    metadata_file=".rag_metadata.json",
    device="cuda"  # 或 "cpu"
)

# 首次同步（全量索引）
count = indexer.sync_directory("docs")
print(f"索引了 {count} 个文档块")
```

### Step 2：增量更新

```python
# 修改文件后，再次同步
count = indexer.sync_directory("docs")

# 如果无变化，会自动跳过
# 输出：📊 新增:0 修改:0 删除:0
#      ✅ 无变化
```

### Step 3：查看统计

```python
stats = indexer.get_stats()
print(f"文件数: {stats['total_files']}")
print(f"文档块: {stats['total_docs']}")
print(f"最后同步: {stats['last_sync']}")
```

**性能对比**：
- 全量索引：250文件 → 60秒
- 增量更新：5文件变化 → 1秒（**60x提升**）

## 🛡️ 场景2：幻觉检测

**适用场景**：需要确保检索结果可靠

### 基础使用

```python
from src.retrieval.hallucination_aware_retriever import HallucinationAwareRetriever

retriever = HallucinationAwareRetriever(
    collection_name="my_docs",
    similarity_threshold=0.5  # 相似度阈值
)

# 检索并检测幻觉
result = retriever.retrieve_with_explanation("PyTorch GPU 安装")

print(f"置信度: {result['confidence']}")
print(f"解释: {result['explanation']}")
print(f"可信: {result['should_trust']}")

if result['should_trust']:
    for doc in result['results']:
        print(f"- {doc['source']}: {doc['similarity']:.2%}")
else:
    print("⚠️ 结果不可信，建议换个问法")
```

### 批量检索

```python
queries = [
    "GPU 加速方法",
    "内存优化技巧",
    "如何训练 GPT-5",  # 应该被拒绝
]

results = retriever.batch_retrieve(queries, top_k=3)

for r in results:
    print(f"{r['query']}: {r['confidence']}")
```

## 🎯 场景3：统一检索接口（推荐）

**适用场景**：需要完整功能，一站式解决

### 快速开始

```python
from src.retrieval.unified_retriever import UnifiedRetriever

# 创建统一检索器（集成所有功能）
retriever = UnifiedRetriever(
    collection_name="my_docs",
    enable_query_optimization=True,    # 查询优化
    enable_hallucination_detection=True,  # 幻觉检测
    similarity_threshold=0.5
)

# 智能检索
result = retriever.search("GPU 加速", mode="smart")

print(f"置信度: {result['confidence']}")
print(f"优化查询: {result.get('optimized_query', 'N/A')}")

for doc in result['results']:
    print(f"- {doc['source']}: {doc['similarity']:.2%}")
```

### 三种模式

```python
# 1. 简单模式（最快）
result = retriever.search("GPU 加速", mode="simple")

# 2. 智能模式（推荐）
result = retriever.search("GPU 加速", mode="smart")

# 3. 扩展模式（最准确）
result = retriever.search("GPU 加速", mode="expanded")
```

## 📊 性能优化建议

### 1. 使用GPU加速

```python
# GPU版本（推荐）
retriever = UnifiedRetriever(device="cuda")

# CPU版本
retriever = UnifiedRetriever(device="cpu")
```

**性能对比**：
- GPU：23.5 ms/query
- CPU：~200 ms/query（**8x慢**）

### 2. 调整批次大小

```python
indexer = IncrementalIndexer()

# 小批次（内存友好）
indexer.sync_directory("docs", batch_size=32)

# 大批次（速度优先）
indexer.sync_directory("docs", batch_size=128)
```

### 3. 调整相似度阈值

```python
# 严格模式（高精度）
retriever = HallucinationAwareRetriever(similarity_threshold=0.7)

# 宽松模式（高召回）
retriever = HallucinationAwareRetriever(similarity_threshold=0.3)

# 推荐值
retriever = HallucinationAwareRetriever(similarity_threshold=0.5)
```

## 🐛 常见问题

### Q1：索引速度慢？

**A**：使用GPU加速 + 增量索引

```python
indexer = IncrementalIndexer(device="cuda")
indexer.sync_directory("docs", batch_size=64)
```

### Q2：检索结果不准确？

**A**：启用查询优化 + 扩展模式

```python
retriever = UnifiedRetriever(
    enable_query_optimization=True
)
result = retriever.search(query, mode="expanded")
```

### Q3：如何避免幻觉？

**A**：启用幻觉检测 + 调整阈值

```python
retriever = UnifiedRetriever(
    enable_hallucination_detection=True,
    similarity_threshold=0.6  # 提高阈值
)
```

### Q4：内存占用太高？

**A**：减小批次大小 + 使用增量索引

```python
indexer = IncrementalIndexer()
indexer.sync_directory("docs", batch_size=32)
```
