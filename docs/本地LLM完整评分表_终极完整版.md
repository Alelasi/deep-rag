**问题**：返回空content，成功率0%

**诊断**：
```python
# 错误
content = message.get('content', '')  # 空字符串

# 检查响应
{
  "message": {
    "content": "",  # 空！
    "reasoning_content": "思维过程..."  # 内容在这里！
  }
}
```

**解决**：
```python
# 正确
content = message.get('reasoning_content', '') or message.get('content', '')
```

**结果**：0/10 → 10/10 ✅

## 💡 技术洞察

### 1. 思维链模型的特殊处理

**发现**：gemma-4-e2b是思维链模型

**特点**：
- 返回两个字段：`content`（空）和`reasoning_content`（完整思维过程）
- 需要特殊代码处理

**价值**：
- 提供详细思维过程
- 适合需要解释的场景
- 但处理更复杂

---

### 2. max_tokens对稳定性的影响

**发现**：nemotron对max_tokens极其敏感

**规律**：
- 太少（<500）：模型拒绝生成
- 适中（1000）：不稳定
- 充足（2000+）：稳定

**教训**：
- 本地模型可能有隐藏的敏感参数
- 需要实验找到最佳配置
- 默认参数不一定最好

---

### 3. 参数量≠质量

**反例**：deepseek-r1-distill-qwen-14b

- 14B参数（最大）
- 3.8分（最差）
- 30%成功率（最不稳定）

**结论**：
- 训练质量>参数量
- 量化/蒸馏可能损失质量
- 需要实测，不能只看参数
