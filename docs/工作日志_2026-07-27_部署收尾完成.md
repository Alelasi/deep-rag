## 问题与解决方案

### 问题 1：gh CLI 权限不足（403）
- **根因**：旧 `GH_TOKEN` 环境变量 X-OAuth-Scopes 为空，无 repo/workflow 权限
- **解决**：用户创建新 PAT（scopes: repo, workflow, read:org），设置到会话环境变量
- **注意**：token 暴露在对话中，需用户后续撤销重新生成

### 问题 2：CI 排队 10h+ 未执行
- **根因**：多个 CI run 排队，无并发控制
- **解决**：添加 `concurrency` 控制自动取消旧 run，新 push 后旧 run 自动取消

### 问题 3：tests/ 目录混入非测试文件
- **根因**：历史开发中 benchmark/evaluate/demo 脚本放在 tests/
- **解决**：16 个非测试文件移到 `scripts/benchmark/`、`scripts/evaluate/`、`scripts/demo/`、`evaluation/results/`
