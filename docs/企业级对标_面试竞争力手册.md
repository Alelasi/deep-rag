## 一、30 秒 / 2 分钟 诚实话术（建议背）

### 30 秒

> 我做了可部署的文档问答系统 DeepRAG：用 **LangGraph** 串 Corrective RAG 纠错链路（评分→改写→再检索→生成→事实校验）；**BM25+向量+RRF** 混合检索，默认走 **Qdrant Server**；对外有 **FastAPI 鉴权/限流/审计** 和 **Streamlit 运维台**。Self-RAG 再生做成开关。指标以固定题集实测为准，例如多学科回归 partial **126/133 pass**、小集 **38/39**，不把历史实验数字当 SLA。

### 2 分钟

> 背景是查 LangChain 文档太散，做了多知识库问答。架构上不是裸向量搜：  
> 1）**检索**：Qdrant 持久化 + 混合检索 + 可选 Rerank；域路由避免「论文库答 INTJ」。  
> 2）**纠错**：文档评分不相关则改写重试；生成后事实校验，可开 Self-RAG 再生。  
> 3）**工程**：`.env` 多后端（Cerebras/Groq/Silicon/Zhipu）+ fallback；API Key、路径沙箱、JSONL 审计；熔断/降级模板。  
> 4）**评测**：golden/e2e/多学科细分支题集 + 本地无依据时联网回退。  
> Multi-Agent coordination 写过消息总线/路由，**尚未挂主 graph**，面试会诚实说是扩展模块。

## 三、项目诚实描述（简历 / 项目页）

### 可写（有代码）

- LangGraph 状态机：分析 → 检索 → 评分 → 改写/Web → 生成 → 事实校验 → 冲突检查  
- Qdrant Server 多集合知识库（工作/论文/心理/社科/哲思灵智含书籍等），同名去重建库  
- 混合检索 BM25+向量 RRF；可选 Silicon Rerank API  
- 域路由 / 源过滤 / 拒识与不可答题规则  
- FastAPI：`/query` `/query/stream` `/health` `/ready` `/metrics` + 鉴权限流审计  
- Streamlit 演示运维台（配置、知识库、评估、错题）  
- 多 LLM 后端与 fallback；进程内熔断降级  
- 评测：固定题集 + 多维度启发式分 + 可选联网回退

## 六、高频面试题（企业向）+ 结合本项目的答法

### A. 基础

**Q1. 什么是 RAG？为什么不用纯微调？**  
检索外部知识再生成；知识更新成本低、可引用、减幻觉。微调适合风格/格式，不适合天天变的文档。

**Q2. 向量检索 vs BM25？**  
语义 vs 关键词；专有名词/型号 BM25 强，同义改写向量强 → 所以 RRF 融合。

**Q3. chunk 怎么选？**  
本项目实验倾向 ~800/overlap~200 量级；过大噪声、过小丢上下文；需按文档结构（标题切）调。

### B. 检索与高级 RAG

**Q4. 什么是 Hybrid + Rerank？**  
先多路召回（BM25+向量）扩召回，再用 cross-encoder/API rerank 提 precision。本项目 Rerank 可走 Silicon API，不占本地 VRAM。

**Q5. Corrective RAG 和 Self-RAG 区别？**  
CRAG 纠**检索**（评分/改写/Web）；Self-RAG 纠**生成**（事实校验/再生）。本项目两者都有，Self-RAG 默认关保延迟。

**Q6. 如何减少幻觉？**  
无证据拒答、mock 不入证、引用约束、事实校验、可选再生、不可答题规则；评测看 faithfulness/拒识正确率。  
另：**时效/新闻意图**不走本地库（防 BM25 把「今日工作日志」当新闻），空 Web 时显式降级说明。

**Q7. 域路由为什么要做？**  
避免「心理问题打到论文库」；`collection_router` + 域不匹配拒答。

### C. 工程与生产

**Q8. 向量库为什么 Qdrant Server？**  
本地 path 单进程锁，建库不能并行开前端；Server HTTP 多客户端。Chroma 曾 HNSW 损坏（项目踩坑）。

**Q9. 如何做 API 安全？**  
API Key、IP 限流、索引路径白名单、审计 JSONL、安全响应头；多租户未做。

**Q10. 如何评测 RAG？**  
离线固定集 + 关键词/结构启发式 + 系统幻觉分；可对齐 RAGAS 四维思想；online 看日志与用户反馈。本项目有 multidim 报告。

**Q11. 可观测要看什么？**  
节点耗时、检索条数、nk 率、429、幻觉分、来源 kb/web；工具上可接 LangSmith/Phoenix（未强制）。

**Q12. 多租户怎么做？（会但未实现）**  
Silo 独立集合 vs Pool+`tenant_id` 强制过滤；权限不能靠 prompt。本项目单用户毕设。

**Q13. LLM 429 怎么办？**  
重试退避、换模型 fallback、熔断降级模板、降 Rerank/降 max_tokens、限流评测并发。

**Q14. LangGraph 相比线性 Chain？**  
条件边、循环（rewrite/regenerate）、状态统一、易插 HITL；代价是复杂度与调试成本。

### D. 行为/项目

**Q15. 最大技术坑？**  
Chroma 索引损坏、local Qdrant 锁、enhanced 误连 Chroma8000、免费 API 429；解决：Server 模式、VECTOR_DB 显式、降级链、限流评测。

**Q16. 为什么默认关 Self-RAG 循环？**  
再生多一次 LLM，延迟+几秒；演示默认 fast，质量模式再开。

**Q17. Multi-Agent 做到哪？**  
`coordination` 有消息总线/路由/熔断设计与测试，**未进主 graph**；主路径仍是单图多节点。
