### 1. 量化技术（Quantization）

#### 1.1 Scalar Quantization（标量量化）⭐ 推荐

**原理**：将 float32 (4 bytes) 压缩为 int8 (1 byte)

```python
# 简化实现
def scalar_quantize(vectors: np.ndarray) -> Tuple[np.ndarray, float, float]:
    """
    vectors: (N, dim) float32
    返回: (N, dim) int8, min_val, max_val
    """
    min_val = vectors.min()
    max_val = vectors.max()
    
    # 映射到 [-127, 127]
    scale = 254 / (max_val - min_val)
    quantized = ((vectors - min_val) * scale - 127).astype(np.int8)
    
    return quantized, min_val, max_val

# 反量化
def scalar_dequantize(quantized: np.ndarray, min_val: float, max_val: float) -> np.ndarray:
    scale = 254 / (max_val - min_val)
    return (quantized.astype(np.float32) + 127) / scale + min_val
```

**性能数据**：
- 压缩比：**4:1**（float32 → int8）
- 召回率损失：**<2%**（98% → 96%）
- 速度提升：**1.5-2x**（int8 计算更快）
- 内存节省：**75%**

**适用场景**：
- ✅ 商业 Embedding 模型（OpenAI/Cohere/Anthropic）
- ✅ 开源模型（sentence-transformers）
- ✅ 生产环境首选（性价比最高）

**参考**：[Vector Quantization: 4-32x Compression](https://tacnode.io/post/vector-quantization-explained)

#### 1.2 Binary Quantization（二值量化）

**原理**：将每个维度压缩为 1 bit（0 或 1）

```python
def binary_quantize(vectors: np.ndarray) -> np.ndarray:
    """
    vectors: (N, dim) float32
    返回: (N, dim//8) uint8（每 8 维打包为 1 字节）
    """
    # 阈值：0（或均值）
    binary = (vectors > 0).astype(np.uint8)
    
    # 打包为 uint8
    packed = np.packbits(binary, axis=1)
    return packed

# 汉明距离搜索（超快）
def hamming_search(query_binary: np.ndarray, db_binary: np.ndarray, k: int):
    """使用 XOR + popcount 计算汉明距离"""
    distances = np.unpackbits(query_binary ^ db_binary, axis=1).sum(axis=1)
    top_k_idx = np.argpartition(distances, k)[:k]
    return top_k_idx
```

**性能数据**：
- 压缩比：**32:1**（float32 → 1 bit）
- 召回率损失：**10-15%**（95% → 80-85%）
- 速度提升：**10-50x**（汉明距离极快）
- 内存节省：**96.875%**

**适用场景**：
- ✅ 第一阶段粗筛（召回 top-1000，再精排 top-10）
- ✅ 超大规模数据（>1B 向量）
- ⚠️ 需要模型支持（Cohere embed-v3 等）

**参考**：[Qdrant Binary Quantization](https://qdrant.tech/course/essentials/day-4/what-is-quantization/)

#### 1.3 Product Quantization（乘积量化）

**原理**：向量分段 + 每段聚类量化

```python
from sklearn.cluster import MiniBatchKMeans

class ProductQuantizer:
    def __init__(self, dim: int = 384, num_subvectors: int = 8, num_clusters: int = 256):
        self.dim = dim
        self.m = num_subvectors
        self.k = num_clusters
        self.subvector_dim = dim // num_subvectors
        self.codebooks = []  # m 个 codebook
    
    def train(self, vectors: np.ndarray):
        """训练 codebook"""
        for i in range(self.m):
            start = i * self.subvector_dim
            end = start + self.subvector_dim
            subvectors = vectors[:, start:end]
            
            kmeans = MiniBatchKMeans(n_clusters=self.k, random_state=42)
            kmeans.fit(subvectors)
            self.codebooks.append(kmeans.cluster_centers_)
    
    def encode(self, vectors: np.ndarray) -> np.ndarray:
        """编码为 PQ codes"""
        N = vectors.shape[0]
        codes = np.zeros((N, self.m), dtype=np.uint8)
        
        for i in range(self.m):
            start = i * self.subvector_dim
            end = start + self.subvector_dim
            subvectors = vectors[:, start:end]
            
            # 找最近的聚类中心
            distances = np.linalg.norm(
                subvectors[:, None, :] - self.codebooks[i][None, :, :],
                axis=2
            )
            codes[:, i] = distances.argmin(axis=1)
        
        return codes
```

**性能数据**：
- 压缩比：**48:1 到 192:1**（取决于 m）
- 召回率损失：**5-12%**（95% → 83-90%）
- 速度提升：**3-8x**（查表计算）
- 内存节省：**98%**

**适用场景**：
- ✅ 十亿级向量（>100M）
- ✅ 内存极度受限
- ⚠️ 需要训练数据（>100K 样本）

**参考**：[Product Quantization: 97% Compression](https://www.pinecone.io/learn/series/faiss/product-quantization/)

### 2. Matryoshka Embeddings（套娃嵌入）🆕 2026 热点

**核心思想**：一个 Embedding 包含多个粒度的信息

```
原始 768 维 Embedding:
[dim 0-63]   → 64 维（粗粒度，快速粗筛）
[dim 0-127]  → 128 维（中粒度）
[dim 0-255]  → 256 维（细粒度）
[dim 0-767]  → 768 维（完整信息，精确排序）
```

#### 2.1 自适应检索策略

```python
class MatryoshkaRetriever:
    """Matryoshka 自适应检索"""
    
    def __init__(self, index_768d, index_256d, index_64d):
        self.full_index = index_768d
        self.mid_index = index_256d
        self.coarse_index = index_64d
    
    def adaptive_search(self, query: np.ndarray, k: int = 10):
        """三阶段检索"""
        # 阶段1：64 维粗筛 top-1000（超快）
        query_64d = query[:64]
        candidates_1000 = self.coarse_index.search(query_64d, k=1000)
        
        # 阶段2：256 维精筛 top-100（快）
        query_256d = query[:256]
        candidates_100 = self.mid_index.search_in_subset(
            query_256d, candidates_1000, k=100
        )
        
        # 阶段3：768 维精排 top-10（准确）
        final_results = self.full_index.search_in_subset(
            query, candidates_100, k=10
        )
        
        return final_results
```

**性能数据**：
- 召回率：**96-98%**（接近全维度）
- 速度提升：**5-10x**（粗筛阶段极快）
- 内存节省：**可选**（可以只存储低维索引）

**适用场景**：
- ✅ 需要动态调整精度/速度
- ✅ 多租户系统（不同用户不同精度）
- ✅ 移动端/边缘设备（资源受限）

**参考**：
