## 🔍 深度分析

### 为什么首次慢，后续快？

```
首次请求 (9.91s)：
├─ 加载模型到GPU显存 (8.5s)  ← 主要耗时
├─ 模型推理 (1.2s)
└─ 网络传输 (0.2s)

后续请求 (2.1s)：
├─ 模型已在显存 (0s)         ← 跳过加载
├─ 模型推理 (1.8s)
└─ 网络传输 (0.3s)
```

**优化方案**：
- 预加载模型（启动时）
- 使用更大模型（qwen3-vl-4b，准确率更高）
- 批量推理（降低平均延迟）
