## 「每个 AI 回答有什么不同」

不是很多模型互比，而是 **同一套 DeepRAG 流水线**，每题的 **证据来源** 不同：

| 标记 | 含义 |
|------|------|
| **kb / 本地知识库** | Qdrant 检索到片段 → LLM 按文档生成（带引用结构） |
| **web / 联网回退** | 本地无可靠依据 → 网页检索 + LLM 总结（答案前常有「【来源：免费联网…】」） |
| **nk / 无知识** | 拒答或空证据（拒识题应如此） |

另外还有：
- 不同 **学科/库**（psychology / work / thesis / social…）
- 不同 **延迟**（本地几秒 vs 联网几十秒）
- 不同 **关键词命中 / 幻觉分 / 是否事实校验通过**

文档总表里有 **来源** 列；正文里每题也写了。

## 各项得分是什么

每题综合分大约由这些拼起来（规则启发式，不是人工打分）：

| 字段 | 含义 |
|------|------|
| **total_score** | 综合分 0–10 |
| **accuracy** | 关键词命中换算的准确分 |
| **keyword_rate** | 期望关键词命中比例 |
| **completeness** | 完整性（长度+准确） |
| **relevance** | 相关性（偏严） |
| **citation_quality** | 引用/结构 |
| **time_score** | 速度分（越快越高） |
| **anti_hallucination** | 反幻觉 |
| **format / fluency** | 格式、流畅 |
| **latency_s** | 实际秒数 |
| **hallucination_score** | 系统事实校验分（越低越好） |
| **fact_check_passed** | 是否过事实校验 |
