## 二、上线前必须完成（运行时）

```bash
# 1) 依赖
pip install -r requirements.txt
pip install -e ".[ui,llm,api,dev]"   # 确保 fastapi/uvicorn/httpx

# 2) 环境
cp .env.example .env
# 生产必填：
# API_KEY=长随机串
# CORS_ORIGINS=https://your-frontend.example
# VECTOR_DB=qdrant
# LLM_BACKEND=...

# 3) 向量库（二选一）
# Qdrant: docker compose up qdrant -d
# Chroma 服务器模式（禁止 PersistentClient 直连已有库）

# 4) 索引 sample 或业务文档（路径须在白名单）
# POST /index 或 UI 索引

# 5) 启动
uvicorn api:app --host 0.0.0.0 --port 8000
streamlit run app.py --server.port 8501

# 6) 测试
pytest tests/test_security.py tests/test_api.py tests/test_self_rag_route.py -v
python evaluation/run_e2e_20.py
```

### 生产配置红线

1. **必须**设置 `API_KEY`  
2. **禁止** `CORS_ORIGINS=*` 对公网  
3. **禁止** 未鉴权开放 `/index`  
4. Chroma：**仅 HttpClient + 常驻 server**  
5. 7B 本地：`ENABLE_RERANKER=false`  
6. 对外 SLA 数字必须来自**当次评测报告**，禁止抄历史 95%

## 三、简历可写（建议表述）

**可以写（有代码/接口支撑）：**

- 基于 LangGraph 的 Corrective RAG 流水线（分析→检索→评分→改写/Web→生成→事实校验）  
- 可选 Self-RAG 再生闭环（配置开关，默认低延迟）  
- 混合检索（BM25 + 向量 + RRF）  
- 生产向 FastAPI：`/query` `/query/stream` `/health` `/ready` `/metrics`，API Key 鉴权、IP 限流、索引路径沙箱、JSONL 审计  
- Streamlit 运维/演示台（知识库、评估、错题集）  
- 离线启发式 RAG 四指标 + e2e_20 回归脚本  
- Docker Compose（API + Qdrant + Postgres 可选）

**慎写 / 需附证据：**

- 「准确率 95%」→ 改为「e2e_20 实测 x/20（日期）」或「历史实验，未作 SLA」  
- 「官方 RAGAS 0.89」→ 改为「离线启发式四指标」  
- 「企业级 K8s 已上线」→ 改为「提供 K8s 清单，本地/Compose 可部署」  
- 「完整 Multi-Agent 生产协作」→ coordination 模块未进主 graph 则勿写生产主路径  

**30 秒项目话术（更新版）：**

> 我做了可部署的 RAG 问答系统：LangGraph 做 Corrective 纠错链路，混合检索提召回；对外提供带鉴权限流的 FastAPI 和 Streamlit 运维台；用固定评测集和离线指标做回归。Self-RAG 再生做成可开关，平衡延迟和质量。

## 四、仍缺（Roadmap，诚实）

| 优先级 | 项 | 说明 |
|--------|----|------|
| P1 | 真实流式 token SSE | 当前 stream 为步骤级，非 token 级 |
| P1 | CI 全绿 + 覆盖率门禁 | 修依赖服务 skip，绑定 e2e |
| P1 | Redis 分布式限流/缓存 | 多副本必备 |
| P1 | 业务知识库增量同步 | 定时 ingest + 版本 |
| P2 | SSO/RBAC 文档级权限 | 元数据过滤 |
| P2 | LangFuse 强制链路 | 现可选降级 console |
| P2 | 灰度与回滚 | 模型/索引版本 dual-run |
| P2 | UI 自动化（Playwright） | 防回归 |

## 五、与「只是 Demo」的分界

| Demo | 可上线工程（本项目方向） |
|------|--------------------------|
| 只 Streamlit 本地问 | API + 鉴权 + 限流 + 审计 |
| 任意路径灌库 | 路径白名单 |
| 指标拍脑袋 | e2e/golden + 报告文件 |
| 幻觉硬编 | no_knowledge 拒答 |
| 版本号混乱 | 包版本 0.2.9 / 能力 v2.9 |

**结论**：当前已具备**小型内网上线**骨架；公网高并发/多租户/合规审计仍需 Roadmap 项。
