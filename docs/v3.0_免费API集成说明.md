## 🔧 配置方式

### 1. 环境变量（.env）

```env
# 自动模式（推荐）：anthropic → groq → cerebras → siliconcloud → zhipu → openai → ollama
LLM_BACKEND=auto

# API Keys
GROQ_API_KEY=gsk_xxx
CEREBRAS_API_KEY=csk_xxx
OPENROUTER_API_KEY=sk-or-v1-xxx
```

### 2. 手动指定后端

```env
# 使用 Groq
LLM_BACKEND=groq
LLM_MODEL=openai/gpt-oss-120b

# 使用 Cerebras
LLM_BACKEND=cerebras
LLM_MODEL=gpt-oss-120b

# 使用 OpenRouter（免费模型）
LLM_BACKEND=openrouter
LLM_MODEL=meta-llama/llama-3.3-70b-instruct:free
```

## 🔄 降级链路

### 自动模式（LLM_BACKEND=auto）

```
anthropic → groq → cerebras → siliconcloud → zhipu → openai → openrouter → ollama → none
```

### 多LLM降级（get_llm_with_fallback）

```
主LLM → Groq → Cerebras → 硅基流动 → Ollama → 规则模式
```
