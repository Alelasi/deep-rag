**修复**：
```python

# 错误：content = message.get('content', '')  # 空
# 正确：
content = message.get('reasoning_content', '') or message.get('content', '')
```

**结果**：成功率 0/10 → 10/10 ✅

### 问题2：nvidia/nemotron不稳定
