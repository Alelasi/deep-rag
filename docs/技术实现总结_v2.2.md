### 1. IncrementalIndexer（增量索引器）

**核心思想**：文件指纹检测变化

**实现细节**：
```python
# 文件指纹（MD5）
def _compute_fingerprint(filepath):
    md5 = hashlib.md5()
    with open(filepath, 'rb') as f:
        for chunk in iter(lambda: f.read(8192), b""):
            md5.update(chunk)
    return md5.hexdigest()

# 检测变化
current_files = {path: fingerprint}
to_add = [p for p in current if p not in metadata]
to_update = [p for p in current if fingerprint changed]
to_delete = [p for p in metadata if p not in current]
```

**关键优化**：
- 批量向量化（batch_size=64）
- GPU加速
- 元数据持久化（JSON）
- 垃圾回收（每100文件）

**性能**：
- 首次：250文件 → 60秒
- 增量：5文件 → 1秒（**60x**）

### 3. QueryOptimizer（查询优化器）

**核心思想**：查询重写和扩展

**实现细节**：
```python
# 同义词映射
synonyms = {
    "安装": ["安装", "配置", "部署"],
    "优化": ["优化", "加速", "提升"],
}

# 缩写扩展
abbreviations = {
    "rag": "retrieval augmented generation",
    "llm": "large language model",
}

# 查询扩展
expanded = [query]
for keyword in keywords:
    if keyword in synonyms:
        for synonym in synonyms[keyword]:
            expanded.append(query.replace(keyword, synonym))
```

**关键优化**：
- 同义词扩展（提升召回）
- 缩写展开（提升理解）
- 查询分解（处理复合查询）
- 最多5个扩展（避免过度）

**效果**：召回率提升~20%

### 4. TieredRAGRetriever（分层检索）

**核心思想**：核心库+外圈库

**实现细节**：
```python
# 查询分类
def _classify_query(query):
    core_keywords = ["pytorch", "cuda", "gpu", "rag", "ai"]
    outer_keywords = ["学习笔记", "读书", "总结"]
    
    core_score = sum(1 for kw in core_keywords if kw in query)
    outer_score = sum(1 for kw in outer_keywords if kw in query)
    
    if core_score > outer_score:
        return "core"
    else:
        return "outer"

# 智能路由
if search_scope == "auto":
    search_scope = self._classify_query(query)
```

**关键优化**：
- 自动路由（根据关键词）
- 去重（避免重复结果）
- 排序（按相似度）
- 支持both模式（搜索两个库）

**效果**：减少搜索范围，提升速度

def search(query, mode="smart"):

## 💡 设计模式

### 1. 策略模式（Strategy Pattern）

**应用**：UnifiedRetriever的三种模式

```python
class UnifiedRetriever:
    def search(self, query, mode="smart"):
        if mode == "simple":
            return self._simple_search(query)
        elif mode == "smart":
            return self._smart_search(query)
        elif mode == "expanded":
            return self._expanded_search(query)
```

---

### 2. 装饰器模式（Decorator Pattern）

**应用**：幻觉检测包装检索器

```python
class HallucinationAwareRetriever:
    def retrieve(self, query):
        results = self.base_retriever.retrieve(query)
        # 添加幻觉检测
        filtered = self._filter_hallucinations(results)
        return filtered
```

---

### 3. 工厂模式（Factory Pattern）

**应用**：检索器创建

```python
def create_retriever(retriever_type):
    if retriever_type == "basic":
        return BasicRetriever()
    elif retriever_type == "hallucination_aware":
        return HallucinationAwareRetriever()
    elif retriever_type == "unified":
        return UnifiedRetriever()
```

## 🐛 问题与解决

### 问题1：索引速度慢

**现象**：250文件索引需要5分钟

**原因**：
- 逐个处理文件
- CPU向量化
- 无批量处理

**解决**：
- GPU加速
- 批量处理（batch_size=64）
- 增量更新

**效果**：5分钟 → 1分钟（5x）

---

### 问题2：检索结果不准确

**现象**：返回不相关内容

**原因**：
- 无相似度阈值
- 无幻觉检测
- 查询不精确

**解决**：
- 相似度阈值（0.5）
- 幻觉检测
- 查询优化

**效果**：准确率 70% → 90%（+20%）

---

### 问题3：内存占用高

**现象**：Python进程占用5GB

**原因**：
- 模型常驻内存
- 批量数据未释放
- 无垃圾回收

**解决**：
- 减小批次大小
- 定期垃圾回收
- 清空CUDA缓存

**效果**：5GB → 2.5GB（50%）
