### 问题3：中文乱码

**现象**：
- Windows环境下运行时，控制台输出中文显示为乱码
- 影响调试信息的可读性

**原因**：
- Windows默认GBK编码
- Streamlit日志输出没有指定UTF-8

**解决方案**：
```bash
# 方案1：设置环境变量
export PYTHONIOENCODING=utf-8

# 方案2：在代码中设置
import sys
sys.stdout.reconfigure(encoding='utf-8')
```

**面试怎么讲**：
> "遇到Windows环境编码问题。通过设置PYTHONIOENCODING环境变量解决，确保跨平台兼容性。这是Windows开发常见坑，记录到项目文档中供团队参考。"
