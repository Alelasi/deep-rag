阶段 1：Qdrant Cloud 注册与配置

免费 1GB Qdrant Cloud 免费层提供 1GB 存储，足够部署 Demo。

1注册 Qdrant Cloud

访问 https://cloud.qdrant.io/，点击 Sign Up。

支持 GitHub / Google / 邮箱注册。推荐用 GitHub 登录（一键授权）。

2创建 Cluster

登录后点击 Create Cluster，填写以下信息：

参数推荐值说明
Cluster Namedeep-rag-demo自定义名称
Cloud ProviderAWS默认即可
Regionus-east-1免费层默认区域
PlanFree (1GB)免费层足够 Demo 使用

点击 Create，等待约 1-2 分钟创建完成。

3获取连接信息

Cluster 创建完成后，在详情页找到以下两个关键信息：

  • Cluster URL：形如 https://xxxxxxxx-xxxx-xxxx.xxxx.aws.cloud.qdrant.io:6333
  • API Key：点击 API Keys 标签页生成新 Key
请记录这两个值，后续需要配置到 Railway 环境变量和 seed 脚本中。
验证连接：在终端执行以下命令验证 Cluster 可达： 
curl -H "api-key: YOUR_API_KEY" YOUR_CLUSTER_URL/collections
返回 {"result":{"collections":[]},"status":"ok","time":0} 即为成功。

阶段 2：Railway 部署

Railway 免费层 每月 500 小时执行时间 + $5 额度，足够 Demo 运行。

1登录 Railway

访问 https://railway.app/，点击 Login，选择 GitHub 授权。

首次使用可能需要授权 Railway 访问 GitHub 仓库。建议只授权 Alelasi/deep-rag 仓库。

2创建项目

点击 New Project → Deploy from GitHub repo → 选择 Alelasi/deep-rag。

Railway 会自动检测 railway.json 配置文件，使用 Dockerfile.streamlit 构建。

如果看不到仓库，点击 Configure GitHub App，在 GitHub App 设置中添加 Alelasi/deep-rag 仓库的访问权限。

3配置环境变量

在 Railway 项目的 Variables 标签页，添加以下环境变量：

必需变量

# === 向量数据库 ===
QDRANT_MODE=cloud
QDRANT_CLOUD_URL=https://xxxxxxxx-xxxx-xxxx.xxxx.aws.cloud.qdrant.io:6333
QDRANT_CLOUD_KEY=your_qdrant_api_key
QDRANT_COLLECTION=deep_rag_docs

# === LLM 后端 ===
LLM_BACKEND=siliconcloud
LLM_MODEL=THUDM/GLM-Z1-9B-0414
SILICONFLOW_API_KEY=your_siliconflow_api_key

# === Embedding ===
EMBEDDING_MODEL=BAAI/bge-base-zh-v1.5

# === 安全 ===
API_KEY=
CORS_ORIGINS=*

# === Pipeline 配置 ===
ENABLE_HYBRID_SEARCH=true
ENABLE_RERANKER=false
ENABLE_SELF_RAG_LOOP=false
USE_LLM_PIPELINE_NODES=false
RETRIEVAL_MODE=enhanced

可选变量（提升体验）

# 备用 LLM（免费降级链）
CEREBRAS_API_KEY=
GROQ_API_KEY=
ZHIPU_API_KEY=

# 日志级别
LOG_LEVEL=INFO
API Key 安全：SiliconCloud API Key 在 cloud.siliconflow.cn 获取。免费层每日有额度限制。

4部署与监控

添加环境变量后，Railway 会自动触发部署。在 Deployments 标签页可以查看构建日志。

构建过程（预计 5-10 分钟）：

  • 拉取 Python 3.11-slim 基础镜像
  • 安装依赖（pyproject.toml + langchain 等）
  • 构建 runtime 镜像（非 root 用户）
  • 启动 Streamlit 服务

部署成功后，Railway 会分配一个公网 URL，形如：

https://deep-rag-production.up.railway.app
自定义域名：在 Settings → Networking 中可以绑定自定义域名（可选）。

阶段 3：向量数据上传

此阶段由 AI 助手执行。用户需要提供 Qdrant Cloud URL 和 API Key。

1配置 seed 脚本环境变量

在本地终端设置以下环境变量：

$env:DATA_SOURCE = "chromadb"
$env:QDRANT_CLOUD_URL = "https://xxxxxxxx-xxxx-xxxx.xxxx.aws.cloud.qdrant.io:6333"
$env:QDRANT_CLOUD_KEY = "your_qdrant_api_key"
$env:QDRANT_COLLECTION = "deep_rag_docs"
$env:CHROMA_SERVER_HOST = "localhost"
$env:CHROMA_SERVER_PORT = "8000"
前提条件：ChromaDB 服务器需在本地运行（chroma run --path "path" --port 8000）。 如果本地用的是 Qdrant 而非 ChromaDB，设置 $env:DATA_SOURCE = "qdrant" 并指定 $env:QDRANT_LOCAL_PATH。

2执行数据上传

cd D:\文档\ai提问相关\工作\deep-rag
python scripts/seed_qdrant_cloud.py

脚本执行流程：

  1. 从本地 ChromaDB/Qdrant 读取向量数据（分批 500 条）
  2. 连接 Qdrant Cloud，自动创建 collection（如不存在）
  3. 分批上传（每批 200 条），显示进度
  4. 验证上传结果（count 对比）

3验证数据

curl -H "api-key: YOUR_API_KEY" \
  YOUR_CLUSTER_URL/collections/deep_rag_docs

# 返回中 points_count 应与本地数据量一致

常见问题排查

Railway 构建失败

问题：Dockerfile 构建超时或内存不足

解决：

  • 检查 Railway Plan 是否为免费层（免费层有 512MB RAM 限制）
  • 如果 pip install 失败，尝试在 Railway Variables 中设置 RAILWAY_DOCKERFILE_PATH=Dockerfile.streamlit
  • 确认 pyproject.toml 中依赖版本固定（避免编译冲突）

Streamlit 启动后白屏

问题：页面打开但无内容

解决：

  • 检查 Railway Logs，确认 QDRANT_CLOUD_URL 和 QDRANT_CLOUD_KEY 已正确设置
  • 确认 LLM_BACKEND 和对应 API Key 已配置
  • 如果是首次启动，等待 30-40 秒让健康检查通过

Qdrant Cloud 连接超时

问题：seed_qdrant_cloud.py 报连接超时

解决：

  • 确认 Cluster URL 格式正确（含 https:// 和端口号 :6333）
  • 检查 API Key 是否有效（在 Qdrant Cloud 控制台重新生成）
  • 网络问题：尝试使用代理或 VPN

Railway 免费额度用尽

问题：Railway 部署暂停

解决：

  • 在 Settings → Sleep 中配置服务休眠时间（如夜间自动暂停）
  • 升级到 Developer Plan（$5/月）获得不限时运行
  • 面试前手动唤醒即可，不需要 24/7 运行

部署前检查清单

用户操作前确认

  • GitHub 仓库 Alelasi/deep-rag 已上线且 CI 通过
  • GitHub Pages 展示页可访问 (https://alelasi.github.io/deep-rag/)
  • 本地 ChromaDB/Qdrant 有向量数据可供上传
  • SiliconCloud API Key 已获取 (cloud.siliconflow.cn)
  • GitHub Token 已撤销并重新生成（安全原因）

  • Railway URL 可访问，Streamlit 界面正常加载

  • Qdrant Cloud collection deep_rag_docs 有数据
  • 测试问题能正常检索和回答
  • README 已更新 Railway Demo URL
  • Showcase Demo 按钮链接已替换为真实 URL
  • 简历已添加 GitHub + Demo + 展示页链接
