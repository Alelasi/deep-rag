### 2. Zero-Vector 查询 Bug 修复

**修复**：改用真实 embedding 向量：

## 问题与解决方案

### 问题1：第三次 HNSW 大规模损坏

**根因**：`repair_v3.py` 在已有数据库路径上创建新的 `PersistentClient`，新 compactor 与已有 HNSW 索引文件冲突，导致 18/19 collections 损坏。

**解决方案**：
1. 删除整个数据库目录
2. 使用单一 PersistentClient 贯穿 build + verify 生命周期
3. 永远不在已有数据库路径上创建新的 PersistentClient

**教训记录**：已写入 project_memory.md，这是第三次发生此类错误。

### 问题2：Streamlit aria_label 不兼容

**根因**：当前 Streamlit 版本不支持 `aria_label` 参数。

**解决方案**：移除所有 4 处 `aria_label` 参数。

### 问题3：CPU 占满

**根因**：PyTorch 默认使用所有 CPU 线程。

**解决方案**：`torch.set_num_threads(2)` + 批次间 `time.sleep(0.15)` + 每10批 `time.sleep(2.0)`。
